## ✨ Features

- 🔐 JWT Authentication
- 💬 Real-time Messaging
- 🟢 Online / Offline Status
- 👤 User Profiles
- 🖼️ Image Sharing
- ⚡ Socket.io Communication
- 📱 Responsive Design
- 🎨 Clean & Minimal UI

### Frontend

- Node.js

## 🚀 Installation

```bash
git clone https://github.com/Jai-Bardiya/Chat-App.git
cd Chat-App
npm install
```

---

## ⚙️ Environment Variables

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5001
NODE_ENV=development
```

---

## ▶️ Run the Project

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```

---

## 🐳 Docker

```bash
docker-compose up --build
```
